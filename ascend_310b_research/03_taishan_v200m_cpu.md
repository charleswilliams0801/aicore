# 3. TaiShan V200M CPU

**TaiShan V200M (泰山 V200M)** is Huawei's CPU core name. [CN122884548A](https://eureka.patsnap.com/patent/CN122884548A) describes four 64-bit Armv8-A V200M cores in Ascend 310B. The [Orange Pi AIpro 20T parameter sheet](https://www.barqilabs.com/aipro-20t-parameters.html) gives four cores at 1.6 GHz. A [Huawei forum post](https://www.hiascend.com/dev/forum/thread-0201177669300121006-1-1.html) reports up to 1.8 GHz for a 20T processor. Keep the board rating and processor maximum distinct.

V200M also appears in a [310P system datasheet](https://www.neusemi.com/CH/skin/default/pdf/HQAIB-ASCEND-176T48GB-HW_V1.3.pdf) with 16 cores at 1.9 GHz. Core name alone cannot identify the SoC. No public standalone V200M datasheet or core technical reference manual was verified.
